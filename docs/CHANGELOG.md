# Changelog

版本演进、关键架构调整、安全加固与已记录的自动化/联调验证摘要。所有条目由早期评审与验收记录汇总而来。

## v1.0.12 — v7（2026-11-13，`versionCode 13`）

- **外部意图与分享安全**：外部 `VIEW` / `SEND` 导入课程只接受 `content://` URI（含显式 Intent），待处理 URI 原子性消费。
- **底部栏生命周期与适配**：`TabBarPlugin` 在 Activity 销毁时解绑并结清未决回调；向壳与同源 iframe 推送真实的系统导航栏 inset（`--hwfee-nav-inset`）。
- **包体裁剪与调试预览**：启用 R8 Full Mode 与资源收缩（保留 `res/raw/keep.xml` 以兼容 Cordova 运行时加载 `config.xml`），移除冗余布局/模板字符串与意外遗留文件；签名 APK 体积降至 10,045,186 字节（较 v6 减少 63.5%）。在 `debug` 源集新增 4 组浅/深色 `GlassPreviews.kt` Compose 预览；包元数据版本同步至 `1.0.12`。
- **验证**：267 项 Web 测试、185 项原生单测通过（3 项 Windows 符号链接用例跳过）；release/debug 仪器化桥接测试在 Activity 重建前后通过；4 组预览渲染通过；Android Lint 0 错误 / 15 警告。

## v1.0.12 — v6（2026-11-11）

- **连续睡眠模式**：开启 15/30/45 分钟睡眠定时后跳过逐句/逐段自动暂停、单句循环与自动评分弹窗，同时保留手动暂停、进度拖拽、倍速调节与修改定时器；到期仅暂停一次并退出模式。
- **进度与音源隔离**：`NativeAudioEngine` 通过 `continuousLesson` 标记将整课切回完整音源播放，保留并恢复开启前的正常练习检查点；库内收藏/复习短句继续使用有界 PCM 片段，不受睡眠定时影响；服务侧使用原子请求状态避免迟到回调覆盖新定时器或反复暂停。
- **验证**：266 项 Web 测试、183 项原生单测通过（3 项 Windows 跳过）；注入式真播放器 Chromium 覆盖 8 组阶段/循环组合、竞态定时器与隐藏框架恢复；Saved review 与 release Lint（0 错误 / 19 警告）通过。

- **性能专项治理**：
  - 库进度字符串键缓存：39 课 × 200 次不变更新从 8,400 次 JSON 解析降至 0 次（jsdom 基准测试 ~227 ms → ~20 ms）。
