[覆盖安装 1.0.11](../dist/HwFee-English-1.0.11.apk)，在「待复习」中使用原来的「记住了」按钮即可移除当前收藏。

版本为 `1.0.11` / versionCode `12`，包含 1.0.10 的逐句音频修复。本次按用户最终确认保留「忘了」「模糊」「记住了」三个名称、位置和等宽布局。所有收藏均计入待复习，不再被旧 `due` 日期排除；「忘了」「模糊」继续保留收藏，「记住了」移除收藏，立即更新列表和待复习统计，并继续下一句或显示完成状态。

收藏卡片和复习面板直接调用原生音频，不跳到课程播放器。播放前精确核对当前课程中的句子原文；不存在或无法打开的句子会移出收藏，不按旧时间跳到其他句子。原生播放使用课程实际音频地址，支持不同文件路径及内嵌音频，句尾沿用有界 PCM 播放。

导入成功后才批量核对旧收藏：每个有收藏的课程读取一次句子数据，仍存在的原句更新编号、时间和收藏键，已消失或被拆分的完整旧句移除。普通页面显示、切换标签和刷新统计只读取本地收藏缓存。导入核对时的暂时读取错误不会被当成句子已删除；点击单个失效收藏则直接清理。核对提交前重读收藏，保留期间新增、取消及复习评分的变化。

接线检查还补了两处：Android 返回键关闭当前复习面板；听完收藏再打开课程时重新载入原生播放会话并恢复课程检查点，避免相同 URL 只发生片段导航而停在隐藏旧播放器。复习结束不改写正常课程进度。关闭按钮和 Escape 同样能关闭面板。

验证结果：

1. 网页测试 200 项通过；Android 单元测试 172 项中 169 项通过、3 项既有 Windows 跳过，无失败。真实 Java 服务输出的课程库页面通过 `node tools/verify-saved-review.mjs` 检查，覆盖未来日期的收藏、原地播放、旧收藏键、三档操作、统计 `3 → 2 → 1 → 0`、空状态与关闭。
2. Android 15 模拟器在实际课程中确认原生收藏片段播放及自然结束、复习不跳页、原名不变、忘了/模糊保留、记住了移除、返回键和课程恢复。正常课程在复习前后保持第 1 段、第二步及 63.39 秒检查点，重新打开仍为 63.39 秒。
3. Chromium 检查了 320×640、360×640、390×844 和深色模式。播放按钮、句子卡片水平居中，三个评分按钮同高等宽，无水平溢出。复习区域预留底部栏空间；较长内容可滚动。示例截图位于 `.tmp/saved-review-preview/`，测量记录为该目录的 `layout.json`。
4. release lint 为 0 错误、18 项既有警告。签名证书与旧版相同，v1/v2 验证通过；APK 内网页资源与当前源码逐字节比对。SHA-256 和机器可读验证记录与安装包一同保存在 `dist/`。

另外检查了课程打开/返回/循环、讲义 PDF、阅读刷新/字号/返回，以及设置中的配置、用量、预加载和外观入口，未发现其他同类可见入口漏接。该项结论来自代码接线检查与现有回归测试，不代表重新调用了所有真实账号接口。课程删除、睡眠定时和高亮类别筛选仍有底层能力但没有界面入口，本次没有新增这些功能。

本次没有操作用户手机或远程推送；手机实际音频输出仍需覆盖安装后复听确认。
